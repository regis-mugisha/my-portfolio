## 🛠️ Technologies Used

- **Frontend**: React 19, TypeScript, Tailwind CSS
- **UI Components**: Radix UI, Lucide React, Tabler Icons
- **Animations**: Framer Motion, Lottie Files
- **Build Tool**: Vite
- **Styling**: Tailwind CSS with custom animations

## ✨ Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile
- **Dark/Light Theme**: Toggle between themes with smooth transitions
- **Interactive Animations**: Smooth scroll reveals and hover effects
- **Contact Form**: Working contact form with Web3Forms integration
- **Project Showcase**: Filterable project gallery with live demos
- **Tech Stack Display**: Organized technology skills with interactive tabs
- **Education Timeline**: Clean timeline showing educational background
- **Performance Optimized**: Lazy loading, optimized images, and performance monitoring

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/regis-mugisha/portfolio.git
cd portfolio
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

### Build for Production

```bash
npm run build
```

## 📁 Project Structure

```
src/
├── components/
│   ├── common/          # Reusable components
│   ├── layout/          # Page sections
│   ├── magicui/         # Custom UI components
│   └── ui/              # Base UI components
├── constants/           # Static data and configurations
├── hooks/               # Custom React hooks
├── lib/                 # Utility functions
├── types/               # TypeScript type definitions
└── utils/               # Helper functions
```

## 🎨 Customization

- Update personal information in `src/constants/`
- Modify projects in `src/constants/projects.ts`
- Customize technologies in `src/constants/technologies.ts`
- Update social links in `src/components/layout/Footer.tsx`
- Replace images in `public/assets/images/`
